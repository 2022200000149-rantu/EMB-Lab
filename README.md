## 🚀 How to Run the Code

### 1. On Physical Hardware (Arduino)
- Wire your circuit according to the pin configurations defined in the sketch headers.
- Open the `.cpp` / `.ino` file in the **Arduino IDE**.
- Select your board model and COM port, then click **Upload**.

### 2. On Tinkercad Simulator
- Check out the interactive circuit models on my [Tinkercad Profile](https://www.tinkercad.com/users/dfpWDsdwu7z) or create a new circuit on [Tinkercad](https://www.tinkercad.com/).
- Place the corresponding components and wire them to the virtual Arduino board.
- Open the code editor, select **Text** mode, paste the code from this repository, and click **Start Simulation**.
